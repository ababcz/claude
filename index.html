Příklad použití

Integrace za minutu

Nainstalujte SDK, nastavte API klíč a začněte konverzovat. Podpora streamingu, nástroje a rozšíření kontextu jsou dostupné hned.

Podporované platformy: Python, TypeScript/JS, a přes REST API cokoliv dalšího.

Zobrazit zdrojový kód →
main.py 
import anthropic

client = anthropic.Anthropic()

# Jednoduchá konverzace
message = client.messages.create(
    model="claude-sonnet-4-6",
    max_tokens=1024,
    messages=[
        {
            "role": "user",
            "content": "Ahoj Claude!"
        }
    ]
)

print(message.content[0].text)
